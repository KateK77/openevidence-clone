# PDF font

ResearchSans-Regular.ttf is a static weight-400 instance of Noto Sans SC, renamed
MedEvidence Research Sans. It is distributed under the accompanying SIL Open Font
License 1.1. It supplies Latin and Chinese glyphs for portable embedded PDF output.

Upstream font: https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf

Upstream license: https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

The static instance was produced using fontTools 4.68.0
`instantiateVariableFont(font, {'wght': 400})`; family, full, unique, and PostScript
names were changed to identify this derivative. ReportLab embeds only glyphs used
by each generated report. Font conversion is a development step, not a runtime dependency.
